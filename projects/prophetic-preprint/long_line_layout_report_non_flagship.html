Key finding: 25 non-flagship lyric lines need multi-line treatment. 17 can be fixed by adding per-section words_overrides (progressive reveal mode). 8 require splitting the synced lyric line into multiple entries because they use line-by-line or karaoke reveal modes, which render each line as a single image.

Pattern Analysis

  • Most affected non-flagship artifacts: the-hidden-library (7 cases), woe-to-you (6 cases), what-is-truth (5 cases), where-ben-has-been (3 cases), marquis-song (3 cases).
  • Reveal-mode split: Progressive mode dominates (17 cases) and supports the simpler words_overrides fix. Line-by-line mode (7 cases) and karaoke (1 case) need synced-line splits.
  • Font size pattern: All problematic lines use font_size: 72, the spoken-word/intro preset. At this size, lines over ~50 characters trigger scaling; lines over ~75 characters often overflow the frame.
  • Audit correlation: The 3 audit overflow warnings among non-flagship songs are all confirmed in this candidate set.

  1. First batch — progressive-mode Critical/Major: Apply words_overrides y-position changes to the 12 progressive Critical/Major cases. These are safe, render-validated, and reversible.
