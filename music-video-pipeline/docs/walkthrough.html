Rendering Architecture
How each frame is composed, from time lookup to final pixel output.
1
_find_active_word(t) → (line_idx, word_idx) using start ≤ t ≤ end
2
if line_idx < 0: Check intro → outro → gap frame (nearest section visuals + 2.5× brightness)
3
get_visual(line_idx, word_idx) → Resolve defaults → section.visual → lines_overrides → words_overrides
4
_draw_background(img, v) → Gradient (16 geometries) + texture (7 types)
5
_apply_bg_motion(img, t, v) → Downsample 2×, apply preset effects, audio reactivity, upsample
6
_layout_line(words, line_idx, v) → Resolve y/x per word, group by y, center each group with tight metrics
7
draw by reveal mode → progressive / karaoke / line-by-line / stacking
8
_compute_animation_progress(t, line_idx) → Enter (0–30%) → steady → exit (last 20%)
9
alpha_composite(text, background) → RGBA text layer over RGB background
10
encoder.write_frame(bytes) → FFmpeg libx264 + AAC streaming

Override Resolution

defaults → section.visual → lines_overrides[line] → words_overrides[line.word]
Each level overrides properties from the previous. If a word has "y": 0.2, it wins over section text_position "center".

Caching Strategy

Background cache: Per section name — identical sections share one background
Styled text cache: Keyed by (text, style, size, family) — words reused across frames
Font cache: Keyed by (family_id, size) — PIL FreeTypeFont objects
Frame dedup: Same (line_idx, word_idx) → reuse raw bytes. Animated: include frame_idx in key
Script.json Schema
The script is the complete visual design specification. Every render decision is controlled by this single file.
{
  "name": "Song Title",
  "defaults": {                   // Base visual properties
    "background_type": "gradient",
    "gradient_colors": ["#162126", "#222b39"],
    "gradient_direction": "radial_center",
    "texture_type": "vignette_soft",
    "texture_opacity": 0.2,
    "font_size": 146,
    "reveal_mode": "progressive",
    "reveal_words": 1,
    "reactivity": ["vocals"],
    "animation_type": "fade",
    "animation_speed": 1.0
  },
  "caption_style": {              // Global text rendering
    "font_family": 0,
    "highlight_color": "#FF8C00",
    "text_position": "center",
    "letter_spacing": 1,
    "text_shadow": false,
    "outline": false
  },
  "sections": [{
    "name": "verse 1",
    "type": "verse",             // Resolved via keyword matching
    "lines": [0, 1],            // Indices into lyrics_synced.json
    "visual": {                    // Section-level overrides
      "text_style": "neon",
      "font_family": 2,
      "gradient_direction": "cross",
      "gradient_colors": ["..."],
      "bg_animation_preset": "dreamy"

CLI Reference
All commands run from the music-video-pipeline directory with PYTHONPATH=src.
init
Create a new project directory with audio and lyrics inputs.
PYTHONPATH=src python3 -m cli.commands init -p ../projects/myproject -a ../song.wav -l ../lyrics.txt
analyze
Extract audio features: beat detection, RMS energy, spectral centroids, onsets.
PYTHONPATH=src python3 -m cli.commands analyze -p ../projects/myproject
sync
Sync lyrics to audio with word-level timestamps. Three-tier: MIDI > vocal stem + Whisper > full mix.
PYTHONPATH=src python3 -m cli.commands sync -p ../projects/myproject
render
Generate script.json and/or render the final video.
PYTHONPATH=src python3 -m cli.commands render -p ../projects/myproject # Generate script only (no render) PYTHONPATH=src python3 -m cli.commands render -p ../projects/myproject --script-only # Render with intro/outro PYTHONPATH=src python3 -m cli.commands render -p ../projects/myproject \ --intro-image ../brand.png --intro-title "Song Title" # Render time range PYTHONPATH=src python3 -m cli.commands render -p ../projects/myproject --start 10.0 --end 60.0
audit
Generate per-word frame samples for visual inspection.
PYTHONPATH=src python3 -m cli.commands audit -p ../projects/myproject
info
Show project information and status.
PYTHONPATH=src python3 -m cli.commands info -p ../projects/myproject
serve
Start HTTP server with browser-based editor for interactive editing.
PYTHONPATH=src python3 -m cli.commands serve -p ../projects/myproject

Selection Algorithm

1. Determine category preference from section type (verse→sans, chorus→display, bridge→serif)
2. Filter font registry to matching category
3. Hash song name + section index for deterministic selection
4. Select font at hash position within category
Same song + same section index → same font. Different songs → different fonts (usually).
