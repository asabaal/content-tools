Implement feature: animate_mode_optional_video_pipeline

Observed state:
The current pipeline only generates static images. There is no animation system, no video output path, and no CLI support for animation.

Goal:
Add a complete, optional Animate Mode that converts the pipeline into an ambient video generator when enabled, while preserving exact existing behavior when disabled.

Scope:
You may ONLY modify:

- CLI argument parsing module
- Main pipeline entry point
- Background rendering module (or equivalent visual generation layer)
- Output writer module

You may CREATE new files ONLY if required for animation logic, but keep them minimal and directly tied to this feature.

DO NOT modify:

- Text rendering logic
- Existing static image generation behavior when animate mode is off
- Any unrelated modules

Required implementation:

1) CLI integration

Add the following flags:

--animate (boolean, default false)
--anim-type (string, choices: drift, flow, pulse, distortion, parallax, reactive, default drift)
--anim-intensity (float, default 0.2, clamp to range 0.0–0.5)
--anim-speed (float, default 1.0, range 0.1–2.0)
--anim-loop (int seconds, default 60)
--anim-seed (int optional)

2) Pipeline behavior

If --animate is false:

- Execute existing pipeline exactly as-is
- Output remains a static image

If --animate is true:

- Switch output mode to video
- Set fps = 30
- total_frames = fps * anim_loop

3) Frame generation loop

For each frame index i from 0 to total_frames:

- Compute normalized time:
  t = i / total_frames

- Generate background frame using animation logic (see section 4)

- Render text layer ONCE and reuse it unchanged across all frames

- Composite:
  final_frame = background_frame + text_layer

- Append frame to video buffer or stream encoder

4) Animation logic (minimum viable)

Implement animation ONLY on background layer

drift:

- Apply slow translation to gradient or texture
- offset_x = t * anim_speed * width * anim_intensity
- offset_y = t * anim_speed * height * anim_intensity

flow:

- Apply smooth noise-based color or texture interpolation over time
- Use sin(t * speed) or noise(t) to shift gradient values

pulse:

- brightness_scale = 1.0 + sin(t * speed * 2π) * anim_intensity * 0.2

distortion:

- Apply small displacement using noise field
- displacement magnitude scaled by anim_intensity

parallax:

- Split background into at least 2 layers
- Move layers at slightly different speeds

reactive:

- If no audio input exists, fallback to pulse behavior
- If audio exists, map smoothed amplitude to intensity

All animation must:

- be continuous
- avoid flicker or sharp transitions
- remain subtle and non-distracting

5) Determinism

If --anim-seed is provided:

- seed all randomness
- ensure reproducible animation output

6) Video output

- Encode frames into video file (mp4 preferred)
- Use standard library or existing encoder already in project if available
- If no encoder exists, implement minimal ffmpeg subprocess call

Output file naming:

- If animate mode: output.mp4
- Else: unchanged behavior

7) Performance constraints

- Do not store all frames in memory if avoidable
- Stream frames to encoder if possible

Success criteria:

- Running without --animate produces identical output to current system
- Running with --animate produces a valid video file
- Video duration matches --anim-loop
- Text remains static and readable
- Background visibly animates according to anim-type
- No crashes or regressions in existing functionality
